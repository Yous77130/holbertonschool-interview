# Star Wars API

Script Node.js qui affiche tous les personnages d'un film Star Wars
en interrogeant la Star Wars API avec le module `request`.

## Usage

./0-starwars_characters.js <Movie ID>

Exemple : `./0-starwars_characters.js 3` affiche les personnages du
"Return of the Jedi", un nom par ligne, dans l'ordre de la liste characters.
